Krauss Safe Speed Model

Implements the Krauss (1998) collision-free car-following model. Dynamically determines safe following speed \(v_{safe}\) considering driver reaction time \(\tau\), deceleration limits \(b\), and driver dawdling imperfection \(\sigma\).

\(v_{safe} = -g\tau + \sqrt{(g\tau)^2 + v_l^2 + 2bg}\)

Intelligent Driver Model (IDM)

Treiber, Hennecke, & Helbing (2000) non-linear continuous acceleration model. Produces human-like smooth acceleration curves, dynamic equilibrium time headways \(T\), and realistic emergency braking under acute approach rates.

\(\dot{v} = a [ 1 - (v/v_0)^\delta - (s^*(v, \Delta v)/s)^2 ]\)

MOBIL Lane-Changing Model

Minimizing Overall Braking Induced by Lane changes (Kesting et al.). Arbitrates lane changes by calculating net collective acceleration gain weighted by driver politeness \(p\), enforcing follower safety braking boundaries \(b_{safe}\) and asymmetric keep-right bias.

\(a_{new} - a_{curr} + p(a_{new,f} - a_{curr,f} + \dots) > \Delta a_{th} \pm a_{bias}\)

Mathematical Rigor

Algorithmic Formulations

Exact governing equations implemented in pure Rust, ensuring microscopic physical consistency.

Krauss Safe Velocity & Dawdling

Calculates the absolute maximum safe speed to guarantee avoiding rear-end impact with leading vehicle \(l\):

\[v_{safe} = -g\tau + \sqrt{(g\tau)^2 + v_l^2 + 2bg}\]

Where \(g = \max(0, \text{gap} - s_0)\), with driver reaction headway \(\tau\). Stochastic driver imperfection is injected via:

\[v(t + \Delta t) = \max(0, v_{des} - \sigma \min(a\Delta t, v_{des})\eta), \quad \eta \sim \mathcal{U}(0,1)\]

IDM Acceleration & Dynamic Gap

Continuous acceleration balancing free-flow cruising acceleration against braking distance:

\[\dot{v} = a \left[ 1 - \left(\frac{v}{v_0}\right)^\delta - \left(\frac{s^*(v, \Delta v)}{s}\right)^2 \right]\]

The dynamic desired gap accounts for current speed and approaching velocity \(\Delta v = v - v_l\):

\[s^*(v, \Delta v) = s_0 + v T + \frac{v \cdot \Delta v}{2\sqrt{ab}}\]

MOBIL Incentive & Safety

Ego vehicle only changes lanes if collective acceleration improves without causing excessive follower braking:

\[\underbrace{a_{new} - a_{curr}}_{\text{Ego Gain}} + p \Big[ \underbrace{(a_{new,f} - a_{curr,f})}_{\text{New Follower}} + \underbrace{(a_{new,of} - a_{curr,of})}_{\text{Old Follower}} \Big] > \Delta a_{th} \pm a_{bias}\]

Follower deceleration is strictly guarded by the safety criterion:

\[a_{new,f} \ge -b_{safe} \quad \wedge \quad a_{new} \ge -b_{safe}\]

Developer Quickstart

Integrate sumo-rs in Seconds

Add to Cargo.toml and simulate multi-lane highways or signalized intersections with a few lines of Rust. 

[dependencies]
sumo-rs = "0.1"
glam = "0.29"
use glam::Vec2;
use sumo_rs::prelude::*;

fn main() -> sumo_rs::Result<()> {
    let mut network = Network::new();

    // Build a 3-lane 1km highway (120 km/h)
    NetworkBuilder::build_straight_road(
        &mut network,
        NodeId::new("start"),
        NodeId::new("end"),
        EdgeId::new("highway"),
        Vec2::new(0.0, 0.0),
        Vec2::new(1000.0, 0.0),
        3,     // 3 lanes
        33.33, // 120 km/h speed limit
    );

    let mut sim = TrafficSimulation::new(network);

    // Spawn a slow truck in the right lane
    let truck = Vehicle::new(
        VehicleId(1),
        LaneId::new("highway_0"),
        50.0,
        15.0, // 54 km/h
        DriverModel::idm_default(),
    );
    sim.add_vehicle(truck)?;

    // Spawn a faster car behind it with MOBIL enabled
    let mut car = Vehicle::new(
        VehicleId(2),
        LaneId::new("highway_0"),
        10.0,
        25.0,
        DriverModel::krauss_default(),
    );
    car.mobil = MobilParameters {
        politeness: 0.2,
        switching_threshold: 0.15,
        safe_decel: 4.0,
        bias_right: 0.1,
        min_clearance: 2.5,
    };
    sim.add_vehicle(car)?;

    // Step simulation at 10Hz
    for _ in 0..200 {
        sim.step(0.1);
    }

    assert!(sim.check_collisions().is_empty());
    println!("Simulation stepped successfully with zero collisions!");
    Ok(())
}
use bevy::prelude::*;
use sumo_rs::bevy_adapter::vehicle_to_bevy_transform;
use sumo_rs::simulation::TrafficSimulation;
use sumo_rs::types::VehicleId;

#[derive(Component)]
pub struct VehicleEntity(pub VehicleId);

pub fn update_traffic_system(
    mut sim: ResMut<TrafficSimulation>,
    time: Res<Time>,
    mut query: Query<(&VehicleEntity, &mut Transform)>,
) {
    // Step simulation deterministically
    sim.step(time.delta_secs());

    for (veh_entity, mut transform) in query.iter_mut() {
        if let Ok(veh) = sim.vehicle(&veh_entity.0) {
            let bevy_tf = vehicle_to_bevy_transform(veh, &sim.network, 0.0);
            transform.translation = bevy_tf.translation;
            transform.rotation = bevy_tf.rotation;
        }
    }
}
